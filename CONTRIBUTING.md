# Contributing / Katkı

Use Node.js 24. Run `npm ci --ignore-scripts`, `npm run check` and
`npm audit --audit-level=low`. Keep strict types, bounded memory, private previews,
fresh permission checks and explicit consent. Add regression tests for changed
behavior. Do not require privileged intents, broad permissions or additional data
retention without a clear discussion. Update both README languages and localized
copy. Never submit tokens, real server data or screenshots containing private text.

Node.js 24 kullan. Yukarıdaki komutları çalıştır. Sıkı tipleri, sınırlı belleği,
özel önizlemeyi, güncel izin kontrollerini ve açık onayı koru. Davranış değişikliğine
regresyon testi ekle. Ayrıcalıklı intent, geniş izin veya ek veri saklama gerektiren
değişiklikleri önce tartış. README'nin iki dilini ve arayüz çevirilerini güncelle.
Token, gerçek sunucu verisi veya özel metin içeren ekran görüntüsü gönderme.

Small pull requests with a concrete problem, resulting behavior and actual test
results are easiest to review. CI has read-only repository access and does not
connect to Discord. Contributions are accepted under the repository's MIT license.

Somut sorun, sonuç davranışı ve gerçek test sonucu içeren küçük PR'lar tercih edilir.
CI depoyu salt okunur açar; Discord'a bağlanmaz. Katkılar MIT lisansı kapsamındadır.
